# NurseAlign Website

A responsive, static, interactive prototype for NurseAlign.

## Preview
Open `index.html` in a web browser.

## Deploy to Vercel
1. Create a new Vercel project.
2. Import this folder through a GitHub repository, or deploy it with the Vercel CLI.
3. Framework preset: Other. Build command: leave empty. Output directory: `.`.
4. Deploy. Set the project name to `nursealignai` only if available.

This project uses fictional demo data, with no backend, hospital integrations, or validated clinical decision support.
